# 聊天命令

## Setu 命令

发送以下任一指令即可获取色图：

```text
来一份色图
来三份白丝瑟图
来9份白丝 萝莉色图
来二份白丝，萝莉色图
来一份白丝,萝莉色图
/色图 白丝 萝莉
/色图 3 白丝
/色图 4 白丝 萝莉
```

- 数量范围支持中文数字
- 标签支持空格、逗号、顿号分隔
- `/色图 2 白丝 r18` 或“来二份白丝色图 r18”请求本次 R18 图片。当前会话为 SFW 时会拒绝，不访问图片源；`r18` 不作为搜索标签，也不修改配置。数量仍使用上面的中文数字规则。

## 随机本子命令

```text
来份本子
来一份本子
来份碧蓝档案本子
/随机本子
/随机本子 碧蓝档案
/本子
/doujinshi
```

- 调用 `https://api.atri.rodeo/v1/doujinshi/random`，下载响应中的全部页图，并按 `delivery.doujinshi_send_mode` 生成 PDF 或 ZIP 压缩包（默认 PDF）。
- 本子标签与 Setu 使用同一套空格、逗号、顿号分隔和标签别名映射；解析出的每个标签都会以重复 `tag` 查询参数传给 API。
- 与 Setu 共用同一套完整 SID 访问控制；被禁止使用色图的会话也不能获取随机本子。
- 两种模式都在所有平台直接发送一个普通文件，不再创建 `Nodes` 合并转发，也不会追加标题或原始地址节点；`archive` 模式的 ZIP 成员按页码顺序命名并保留图片扩展名，若上游没有扩展名则使用 `.bin` 保留原始字节。
- 文件名使用 API 返回的本子标题，并对平台不允许的路径字符做安全替换；PDF 使用 `.pdf`，压缩包使用 `.zip`。
- 生成文件会写入插件运行数据目录，供 AstrBot 在发送期间读取；不使用插件目录下的 `data/`。
- OneBot/NapCat 群聊的本子普通文件消息是否自动撤回由全局 `delivery.auto_revoke_targets` 中的 `doujinshi` 控制，默认启用；它与色图、今日运势共用 `delivery.auto_revoke_delay`。填 `1800` 即为 30 分钟，`0` 可关闭全部自动清理。任务保存在插件数据目录的可恢复队列中，重启后仍会恢复。
- 启用自动撤回时，本子发送会使用 OneBot 原始 `send_group_msg` 取得普通文件消息的 `message_id`，到期调用 `delete_msg`；不依赖 `get_group_root_files` 或 `delete_group_file`。

## 今日运势与刷新

- `/今日运势`，别名 `/jrys`：查看当前会话中的今日运势。
- `/刷新运势`：刷新本人在当前会话的运势；普通用户需开启 `fortune.allow_user_refresh`，管理员可直接使用。
- `/刷新运势@用户`：管理员 At 一位用户，刷新该用户在当前会话的运势。
- `/刷新全局运势`：超级管理员清理当天所有运势及卡片缓存，下次查看时重新生成。

同一会话中同一用户每天一份运势。切换主题沿用当天星级。渲染失败时，文字运势取自当前主题的 `text.json`。

## 个人运势偏好

```text
/运势偏好 查看
/运势偏好 主题 arona
/运势偏好 标签 猫耳 白发
/运势偏好 重置主题
/运势偏好 重置标签
```

不带子命令时显示框架生成的帮助。主题可选 `arona`、`endfield`、`persona5`、`minecraft`、`minimal`、`random`。搜索标签按“个人偏好 → 当前 SID 会话配置 → 插件默认值”生效；主题按“个人偏好 → 插件默认值”生效。分级继续受会话设置约束。偏好使用框架返回的 `user_id` 保存，在各群聊与私聊共享。

主题也支持别名，例如 `/运势偏好 主题 蔚蓝档案`、`/运势偏好 主题 Blue Archive`、`/运势偏好 主题 随机`。英文忽略大小写，保存时统一使用主题目录名或 `random`。各主题的别名写在 `template.yaml` 的 `aliases` 中，修改后重载插件生效。

## 入口开关

`/色图` 的别名仍为 `/setu`。普通命令、短语入口、LLM 工具分别由 `setu_general.commands_enabled`、`natural_language_enabled`、`llm_tools_enabled` 控制。关闭后移除相应注册，保存并重载生效。

短语模板仍使用 `trigger_templates`。图片可用 `{数量}`、`{标签}`，本子可用 `{标签}`，运势填写固定短语。框架原生子命令负责偏好参数解析。

`delivery.doujinshi_enabled=false` 时停止本子下载；`fortune.enabled=false` 时移除运势命令和工具，并跳过运势处理器及渲染器初始化。
