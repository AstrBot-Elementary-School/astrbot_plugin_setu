# 聊天命令

## Setu 命令

发送以下任一指令即可获取色图：

```text
来一份色图
来三份白丝瑟图
来9份白丝 萝莉色图
来二份白丝，萝莉色图
来一份白丝,萝莉色图
/setu 白丝 萝莉
/setu 3 白丝
/setu 4 白丝 萝莉
```

- 数量范围支持中文数字
- 标签支持空格、逗号、顿号分隔
- `/setu 2 白丝 r18` 或“来二份白丝色图 r18”请求本次 R18 图片。当前会话为 SFW 时会拒绝，不访问图片源；`r18` 不作为搜索标签，也不修改配置。数量仍使用上面的中文数字规则。

## 随机本子命令

```text
来份本子
来一份本子
来份碧蓝档案本子
/随机本子
/随机本子 碧蓝档案
/本子
/doujinshi
```

- 调用 `https://api.atri.rodeo/v1/doujinshi/random`，下载响应中的全部页图，并按 `delivery.doujinshi_send_mode` 生成 PDF 或 ZIP 压缩包（默认 PDF）。
- 本子标签与 Setu 使用同一套空格、逗号、顿号分隔和标签别名映射；解析出的每个标签都会以重复 `tag` 查询参数传给 API。
- 与 Setu 共用同一套完整 SID 访问控制；被禁止使用色图的会话也不能获取随机本子。
- 两种模式都在所有平台直接发送一个普通文件，不再创建 `Nodes` 合并转发，也不会追加标题或原始地址节点；`archive` 模式的 ZIP 成员按页码顺序命名并保留图片扩展名，若上游没有扩展名则使用 `.bin` 保留原始字节。
- 文件名使用 API 返回的本子标题，并对平台不允许的路径字符做安全替换；PDF 使用 `.pdf`，压缩包使用 `.zip`。
- 生成文件会写入插件运行数据目录，供 AstrBot 在发送期间读取；不使用插件目录下的 `data/`。
- OneBot/NapCat 群聊的本子普通文件消息是否自动撤回由全局 `delivery.auto_revoke_targets` 中的 `doujinshi` 控制，默认启用；它与色图、今日运势共用 `delivery.auto_revoke_delay`。填 `1800` 即为 30 分钟，`0` 可关闭全部自动清理。任务保存在插件数据目录的可恢复队列中，重启后仍会恢复。
- 启用自动撤回时，本子发送会使用 OneBot 原始 `send_group_msg` 取得普通文件消息的 `message_id`，到期调用 `delete_msg`；不依赖 `get_group_root_files` 或 `delete_group_file`。

## 今日运势与刷新

- `/今日运势`、`/jrys` 或纯文本“今日运势”“jrys”：获取今日运势，受运势访问控制约束。
- `/运势刷新`、`/运势刷新 我`：刷新自己的运势；管理员可用，普通用户须开启 `fortune.allow_user_refresh`，并通过运势 SID 权限检查。
- `/运势刷新 本群`：触发本群刷新操作，需要管理员权限且必须在群聊中。
- `/运势刷新 全局`：触发全局刷新操作，需要超级管理员权限。

运势卡片采用深色全息样式，按运势等级切换配色，显示用户名、日期、星级、运势描述和寄语。

旧刷新命令别名、会话配置、运势开关和黑白名单管理命令均已移除。配置统一在插件配置中调整，见[配置参考](./configuration.md)。

## 短语入口

`setu_general.natural_language_enabled` 控制自然语句，不影响 `/setu`、`/随机本子`、`/今日运势` 和 LLM 工具。`trigger_templates` 默认提供图片、本子和运势三条规则；短语留空时沿用本文原有说法。填写后只匹配自定义的整句，按列表顺序执行第一条匹配，不使用正则。

图片短语可写“给我{数量}张{标签}图片”，本子可写“找本{标签}本子”，运势填写固定短语。数量、标签可省略，分别默认为 1 和空；未知或重复占位符会阻止加载。删除某条规则就删除该入口，清空列表则关闭全部短语入口。

## 行为说明

- `delivery.doujinshi_enabled=false` 时，本子命令与短语只提示停用，不发起下载。`fortune.enabled=false` 时，运势获取、刷新和后台预生成全部停用，已有文件、记录和撤回任务保留。
- 图片、本子和运势提示使用内置文案，不再开放消息覆盖。
- 运势卡片渲染失败时保留纯文本降级。
- 请求和发送均使用当前会话模板覆盖后的配置。
