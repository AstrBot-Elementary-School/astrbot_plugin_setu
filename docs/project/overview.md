# 项目概览

`astrbot_plugin_setu` 提供多源随机图片、随机本子 PDF/ZIP、平台适配发送和每日运势。

## 核心能力

- Lolicon、SexNyan、自定义 API 与多源策略。
- 标签搜索、别名、数量和内容分级；可配置短语入口与单次 `r18` 标记。
- 图片直发、合并转发、Docx、HTML 卡片及 NapCat 传输策略。
- 全局配置加会话模板覆盖，Setu／运势分别按完整 SID 控制会话访问。
- 运势卡片生成、缓存和活跃用户预生成。
- 图片获取、运势获取与刷新 LLM 工具。

## 配置只有一个入口

所有设置都在 AstrBot 插件配置中管理：`safety` 管权限，`session_configs` 用模板管理会话差异。保存后重载，不提供独立 Pages、管理命令或配置修改工具。

错误文案集中管理但不开放自定义，发送成功不追加提示（`/刷新运势` 刷新自己时返回固定确认）；内部调优采用固定默认。旧会话数据只在升级时迁入一次，不继续作为第二配置来源；旧裸 ID 权限需明确替换为完整 SID 规则。

## 分层取舍

- `domain`：标签、访问控制、运势等级等稳定规则。
- `application`：图片用例与只读会话配置解析。
- `infrastructure`：AstrBot、provider、sender、配置迁移及运势持久化。
- `shared`：配置模型、错误文案、日志及发送缓存。

运势与图片缓存仍以用户和日期归属，会话标识是生成背景的上下文，不是新的存储主键。
